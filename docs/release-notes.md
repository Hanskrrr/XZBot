# XZBot 0.9.0 RC4（本机开发版，尚未发布）

- 修正切片标题过滤配置；角色动态界面显示近一天抓到、匹配及过滤的数量。切片标题与发布时间独立保留最多 24 条，不与 6 条动态正文共用名额。
- 每次对话组装带入北京时间与 UTC；近期事件按来源时间判断，预算裁剪与轨迹同步。新增“此刻时间与最近发生的事情”可编辑提示词；沿现有工具循环按需补查，不增加每条消息的独立判断调用。
- 管理页新增版本更新：可配置独立 HTTPS 更新源、自动检查、自动下载、管理员安装并重启。保留私有目录、拒绝覆盖 Git 开发目录和修改过的程序文件，提供程序回滚和 SQLite 备份。
- 前端拆为页面、样式、主脚本及动态/更新功能脚本；后端新增 context 与 updates 模块。遗留大模块继续逐步整理，未宣称完成全面架构重构。

本轮仅部署到本机，没有推送或发布到个人 GitHub。更新源默认留空。RC3 下载者需要先手动升级一次，后续才可使用更新器。Windows/Linux 的更新安装与真实 QQ 收发仍需目标系统验收；本机离线与合成环境测试不是三端实机证明。
