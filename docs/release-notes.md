# XZBot 0.9.0 RC7

下载入口、源码安装手册和程序内置的“官方更新源”统一使用本项目 Gitee 发行版。无需下载者填写账号或令牌；已有自定义更新源保留。早期版本需先安装本版，再使用新的内置更新通道。

更新器按系统和架构匹配完整发行版，校验 SHA256 和包内文件清单；未完成的附件上传不会进入更新候选。发布程序支持校验后跳过已有文件、一次有条件的补传，以及明确的失败结果，最后才上传更新清单。

合入上下文过长时的重试修复、微博无年份日期解析修复；管理页支持页面历史导航、未保存修改提醒，并调整了顶部布局与页面指引。

Windows x64、macOS Apple Silicon、Linux x64 各附 ZIP、SHA256 与原生安装验证报告。首次启动需要联网安装依赖；QQ/NapCat 仍需单独安装并扫码。完整步骤见包内 docs/user-guide.md 与 docs/releases.md。私人密钥、聊天与 QQ 登录态不进入发行包。
