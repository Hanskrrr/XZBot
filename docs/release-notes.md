# XZBot 0.9.0 RC3

下载对应系统的 `XZBot-0.9.0rc3-*.zip`，解压后运行 `Start-XZBot`。请下载带平台名称的发行资产，不要用 GitHub 自动生成的 Source code 包替代安装包。

- 自带阿梓、灰泽满两个基础 Profile：人设、额外提示词、预设问答、别名、背景资料与音色 ID。新安装自动创建，已有部署可以从角色页导入独立副本。
- 额外提示词可保存为当前角色的默认版本；角色动态采用近期生活视角，原始事件与时间保留。
- 订阅对象编辑、立即获取、获取与推送记录、微博登录态诊断、近期动态上下文预览。
- 多 QQ 运行路径选择、SnowLuma 已有环境适配与状态说明。macOS 原生 NapCat 尚未通过本项目实机验收，仍属试验路径。

**Windows：** XZBot 原生运行，无需 WSL/Lima。QQ 使用另装的 Windows 原生 NapCat + QQ；按包内 `READ-ME-FIRST.md` 导入连接配置，再扫码、绑定自己的账号并配置 Owner。此 ZIP 不捆绑 QQ/NapCat，不是离线全家桶；首次启动需联网下载 Python 3.12 和锁定依赖。

**隐私：** 不含 API key、Cookie、管理令牌、QQ 登录态、Owner、群白名单、成员记忆或私人聊天。音色 ID 不附带授权，语音默认关闭。基础角色属于非官方同人角色，第三方资料保留各自许可与来源。

只有三平台的原生测试及**实际 ZIP 解压、启动脚本、双 Profile、管理服务和 AstrBot 桥接**检查全部通过才发布。每个 ZIP 有 SHA256 与验证报告；CI 没有登录真实 QQ，也未调用真实模型/语音服务，不能将其解释为 Windows/Linux 腾讯收发已实机验收。当前按 Release Candidate 发布。
