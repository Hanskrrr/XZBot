# XZBot 0.9.0 RC4

- 修正切片标题过滤配置；角色动态界面显示近一天抓到、匹配及过滤的数量。切片标题与发布时间独立保留最多 24 条，不与 6 条动态正文共用名额。
- 每次对话组装带入北京时间与 UTC；近期事件按来源时间判断，预算裁剪与轨迹同步。新增“此刻时间与最近发生的事情”可编辑提示词；沿现有工具循环按需补查，不增加每条消息的独立判断调用。
- 管理页新增版本更新：默认 GitHub Releases，也可配置独立 HTTPS 更新源；自动检查、自动下载、管理员安装并重启。保留私有目录、拒绝覆盖 Git 开发目录和修改过的程序文件，提供程序回滚和 SQLite 备份。
- 前端拆为页面、样式、主脚本及动态/更新功能脚本；后端新增 context 与 updates 模块。遗留大模块继续逐步整理，未宣称完成全面架构重构。

- 修复续聊判断偏向默认认领对话的问题，结合其他群友插话判断真正的交谈对象；新增可编辑的对话对象与引用提示词。
- QQ 原生回复携带同一会话中被引用的原文、作者和时间；不跨群读取，也不把旧附件冒充当前配图。取不到原文时显式标记。
- 补齐简明操作手册、Windows/macOS/Linux 源码安装和原生构建步骤，以及 Gitee 镜像/发行版说明。
- 三端打包只在版本标签或手动运行时执行，普通提交保留源码隐私检查，避免重复触发完整安装。

下载对应系统的 ZIP 并解压运行 Start-XZBot。Windows 为原生运行，无需 WSL；QQ/NapCat 单独安装登录，首次依赖安装需要联网。内置阿梓和灰泽满基础角色，不包含私人密钥、群号、历史或 QQ 会话。

每个包附 SHA256 与原生安装验证报告，验证核心和固定版本 AstrBot 桥接，不代表已经在三个系统完成真实 QQ 收发。RC3 下载者需要先手动升级一次，后续才可使用更新器；源码目录继续用 Git 管理。
