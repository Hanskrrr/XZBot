# XZBot 0.9.0 RC8

本候选版更新群聊参与、成员记忆、消息处理记录和管理页面，并修复 Gitee 更新下载的可信来源误判。

## 群聊参与与回复

- 每个角色独立使用自己收到的公开消息和已确认发送的回复进行参与规划，不读取其他账号的配置、人设、记忆或待发送内容。明确点名进入直接回复流程；含糊指代、引用冲突和多人交错先判断回应对象与本地消息依据。
- 同一群的待处理消息进入有界队列，降低生成期间漏掉其他成员发言的情况；同一成员尚未处理的普通连续发言可合并，明确 @、引用和指令保留。相关转向或权限变化会在发送前取消过时计划。
- 其他 Bot QQ 号由各角色显式配置。允许有限互动后，每次有效真人消息最多为本角色提供一次回应其他 Bot 的机会；默认关闭，普通接话和冷场发言不能绕过限制。重复回复会在发送前拦截。
- 原生 @ 保留成员身份、群名片和引用关系；只有 @ 没有正文时也可自然应声。引用已发送的角色回答可追溯原问题，仍遵守本群历史保存与成员权限。
- 群语音统一使用本群额度，并新增输入指定文字后直接合成发送的入口。

## 成员记忆与消息记录

- 新增成员介绍与近 72 小时互动摘要。手动固定介绍不会被自动整理覆盖；自动整理在后台按条数或等待时间触发，保留来源与实际互动时间，只将已确认发送的回复作为共同经历。
- 正文以 `（（` 或 `((` 开头可让 XZBot 完全忽略该条消息及附件，不触发模型、上下文、历史、记忆或调用轨迹；不会影响下一条正常消息。
- 调用轨迹可按消息查看参与规划、生成、重试、联网搜索、语音及最终发送结果，并显示排队、接收类型和服务退避原因。
- 修正无效 JSON 或参与规划字段触发整个角色服务退避的问题，避免其他群的明确 @ 被连带拦截；真实网络、限流和服务故障仍保留退避。

## 近况、管理与更新

- 角色近况优先使用新鲜的直播状态，并保留实际观察到的开关播时间区间；“刚开播／刚下播”有可配置时间范围，明确矛盾的候选在额度允许时最多重写一次。
- 管理页更新群聊参与、成员档案、消息详情与概览，统一显示额度、处理状态和后续操作入口。
- 修复 Gitee 附件跳转到 `foruda.gitee.com` 时被误判为不可信来源的问题。保留仓库附件匹配、HTTPS、下载域名、SHA256 和包内文件清单校验。

## 安装与升级

提供 Windows x64、macOS Apple Silicon、Linux x64 的 ZIP、SHA256 与原生安装验证报告。首次启动需要联网安装依赖；QQ/NapCat 仍需单独安装并扫码。完整步骤见包内 `docs/user-guide.md` 与 `docs/releases.md`。

升级后核心服务和 QQ 桥接都需加载新代码。旧版若遇到 Gitee 可信来源报错，请从本项目发行版手动下载本版；源码目录通过 Git 更新。私人密钥、聊天与 QQ 登录态不进入发行包，自动更新清单仅在三端安装包全部上传并校验通过后发布。
